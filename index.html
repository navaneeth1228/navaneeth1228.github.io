At Copani LLC I built a BERT-based NLP pipeline that triages 50+ customer emails a day behind a human-in-the-loop review gate.

I hold an M.S. in Engineering Science (Data Science) from SUNY Buffalo and a B.E. in Computer Science (AI & ML). I care about systems that are tested, monitored and auditable, not notebooks.

Read the case study

Problem

Build a reliable, repeatable path from raw e-commerce source data to curated, analysis-ready tables, with proof that every record landed and an early warning when anything drifts.

My role

Designed and built it end to end: the data contract, both Airflow DAGs, the bronze and silver layers in Snowflake, and the Monte Carlo monitoring.

Key decisions

  • Validate before load: 18 checks gate each batch, so bad data never reaches bronze.
  • Audit every load: per-table audit logging makes each run traceable (144 audited loads).
  • Dynamic Tables for silver: declarative refresh in 0.6–3.0 s, no extra scheduler to maintain.
  • Single-session load with timeouts: 10 tables in 39–46 s; full daily run about 1–1.5 minutes.

Result

  • 100% of 68,166 bronze keys reconciled into silver, zero rejected rows.
  • 88 Monte Carlo monitors covering freshness, volume, schema and field quality.
  • 4,500–4,800 records ingested per daily run, fully audited.

What I'd do differently

Add a gold layer of business-facing marts, express the silver transformations as dbt models with tests and docs, and replace the synthetic source with a real change-data-capture feed.
